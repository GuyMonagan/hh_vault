# HH Vault
HH Vault — это ETL-пайплайн и аналитическое консольное приложение для сбора, хранения и анализа данных о вакансиях с платформы HeadHunter (hh.ru).

Проект автоматически загружает информацию о выбранных компаниях и их вакансиях в базу данных PostgreSQL и предоставляет удобный интерфейс для выполнения аналитических запросов.

---

## 🎯 Основная цель
Спроектировать реляционную базу данных, написать скрипты для её автоматического создания, реализовать сбор данных через публичное API hh.ru и создать класс для выполнения бизнес-запросов к данным.

---
## 📦 Возможности
### 🔄 Автоматизированный ETL-процесс:
- Получение данных о компаниях и их вакансиях через публичное API hh.ru.
- Загрузка структурированных данных в PostgreSQL.

### 🗃️ Управление данными:
- Автоматическое создание базы данных и таблиц.
- Связь вакансий с компаниями через внешний ключ (FOREIGN KEY).

### 📊 Аналитические запросы:
- Получение списка компаний и количества вакансий.
- Просмотр всех вакансий с детальной информацией.
- Расчёт средней зарплаты.
- Поиск вакансий с зарплатой выше средней.
- Поиск вакансий по ключевым словам в названии.

## 🏗️ Архитектура и стек технологий
- Язык: Python 3.11+
- База данных: PostgreSQL
- Poetry — управление зависимостями и запуск проекта

### Основные библиотеки:
- psycopg2-binary — для работы с PostgreSQL
- requests — для запросов к API hh.ru
- python-dotenv — для управления настройками

## Инструменты качества:
- (по желанию) pytest — для тестирования
- flake8, black — для линтинга и форматирования

## ⚙️ Установка и настройка
Клонируйте репозиторий:

```
git clone <ссылка-на-ваш-репозиторий>
cd hh_vault
```
Создайте и активируйте виртуальное окружение:

```
python -m venv .venv
```
# Для Linux/macOS:
```
source .venv/bin/activate
```
# Для Windows:
```
# .venv\Scripts\activate
```

Установите зависимости:

`poetry install`

Убедитесь, что PostgreSQL установлен и запущен.
Базу данных можно создать вручную через консоль:
```
psql -U postgres
CREATE DATABASE hh_vacancies
```
Или любой способ, которым вы управляете PostgreSQL (pgAdmin и т.д.)


Настройте переменные окружения:

Скопируйте файл .env.example в .env:

```
cp .env.example .env
```
Отредактируйте .env, указав ваши данные для подключения к БД:

```
HH_API_URL=https://api.hh.ru
DB_NAME=hh_vacancies
DB_USER=your_username
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

В файле src/config/config.py укажите список ID 10 компаний с hh.ru, данные которых вы хотите собирать.

## 🚀 Запуск
Основной скрипт запускается командой из корневой директории проекта:

```
poetry run python main.py
```
После запуска программа выполнит следующие шаги:

Создаст необходимые таблицы в базе данных (если они не существуют).

Загрузит данные о компаниях и вакансиях с hh.ru.

Заполнит таблицы полученными данными.

Предоставит консольный интерфейс для выполнения аналитических запросов с помощью класса DBManager.

## 📄 Документация по API

- [API HeadHunter](https://github.com/hhru/api)

Для получения данных используется Публичное API HeadHunter.

Информация о компании: GET /employers/{employer_id}

Вакансии компании: GET /vacancies?employer_id={employer_id}
